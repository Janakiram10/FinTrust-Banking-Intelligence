# FinTrust LinkedIn Launch Post

I completed **FinTrust Banking Intelligence**, an end-to-end Banking Data Analytics and BI portfolio project built to give management a unified view of customers, transactions, deposits, lending, fraud, credit risk, churn and branch performance.

The core analytics work uses SQL and Python to clean, transform and validate data, calculate business KPIs and explore customer behavior, transaction activity, portfolio risk and operating performance. I then built a six-page Power BI dashboard for interactive, decision-focused analysis.

The project covers **257,969 records**, including **5,000 customers** and **120,000 transactions**. I also added modern analytics depth through a locally validated PySpark and Delta Lake Bronze-Silver-Gold pipeline, **11 dbt models**, **12 passing dbt tests**, **8 repository tests** and an eight-task Airflow DAG design.

The dashboard screenshots demonstrate interactive filtering using the North/East regional view. All data is synthetic, and cloud components are presented as deployment-ready architecture rather than a production Azure implementation.
